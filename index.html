How to Add and Enable an API Key (Step-by-Step Guide)
Step 1: Click Get API Key on any provider card below (such as Google Gemini, Groq, or OpenRouter) to generate and copy your API key.
Step 2: Go to Settings → Model settings. Select a provider on the left or click + Add provider to add a custom Provider Name, Base URL, and Model ID.
Step 3: Paste your key into the API Key input field and click Enable API Key (or Enable Provider in the top header).
Step 4: Click Use next to your preferred model in the Model list, then return to the Workspace to start chatting with full persistent memory.
