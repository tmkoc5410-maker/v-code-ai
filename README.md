# V.Code — AI Coding Environment & Multi-Model Workspace

**V.Code** is a fast, responsive, client-side AI coding environment and workspace built with pure HTML5, CSS3, and Vanilla JavaScript.

## Key Features
- **Strict API Key & Model Governance**: Connect Google Gemini, Groq, OpenRouter, OpenAI, Anthropic, DeepSeek, Mistral, or xAI Grok with your own API key.
- **1-Click Live Free-Model Harvester**: Fetch live `:free` and active model IDs directly from OpenRouter, Groq, and Gemini in Settings.
- **Interactive Chat & Modular Code Cards**: Live typing animation, line-numbered syntax-highlighted code cards, and a collapsible Right Code Viewer (`Edit`, `Undo`, `Copy`, `Save`, `Save All`).
- **Smart `SEARCH/REPLACE` File Patching & Version History (`v1`, `v2`)**: Updates existing files in place and tracks file versions.
- **Client-Side Syntax Verification Gate & 1-Click `Auto-Fix`**: Automatically verifies JS/TS, JSON, CSS, and HTML balance and repairs syntax errors in one click.
- **Client-Side Security Vault**: Encrypts saved API keys in browser storage (`vcvault:v1:`), redacts secrets from memory notes, validates HTTPS endpoints, and includes a 1-click **Clear All API Keys** button.
- **All-Device Responsive UI**: Works seamlessly across mobile phones, tablets (with slide-over drawers), and desktop screens with Dark, Light, and Midnight themes.
